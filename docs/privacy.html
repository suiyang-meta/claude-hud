HUD for Claude — Privacy Policy

Last updated: August 21, 2026

HUD for Claude is a desktop app (macOS) with an optional Chrome extension. Both are built by a single independent developer. This policy explains exactly what is read, where it goes, and what is stored.

Short version

No data is sent to the developer or to any third party. There are no servers, no analytics, no accounts, no tracking. The app reads files already on your computer, and makes one kind of network request: asking Anthropic about your own account, using your own credential that Claude Code already stored on this machine.

What the desktop app reads

  • Your Claude Code credential, from the macOS keychain (Claude Code-credentials). macOS will ask your permission the first time. The app uses it only to call Anthropic's own API on your behalf, and never writes it to a file, a log, or anywhere off this machine.
  • Your account name, email, and plan tier — returned by Anthropic when the app asks who the credential belongs to, so the panel can show whose usage it is displaying. Shown on your screen only.
  • Your plan's usage allowance — session and weekly percentages, and when they reset.
  • Your local Claude Code transcripts (~/.claude/projects/) — but only each API call's timestamp, model name, and token counts. The text of your prompts and Claude's replies is never read, stored, or transmitted.

What the desktop app writes

  • Back to the keychain: Anthropic issues a new credential each time the old one is renewed and invalidates the previous one, so the app must store the replacement or Claude Code would be signed out. It writes back only that renewed credential, to the same entry it read from, and verifies the write.
  • A local cache at ~/Library/Application Support/claude-hud/usage-cache.json — token counters per day and model, so the app doesn't rescan every file each time. It holds numbers only: no prompts, no replies, no credentials.
  • A preferences file — your "Launch at Login" choice, pet settings.

Network requests

The app talks to exactly one host: api.anthropic.com, to read your own account's usage allowance and to renew your own credential. Nothing is sent to the developer. There are no analytics SDKs, crash reporters, ad networks, or third-party APIs of any kind.

The Chrome extension

On macOS it is not needed — the keychain route above supplies the allowance, so there is no browser tab and no claude.ai session involved.

On Windows it is how the allowance arrives. The keychain is macOS-only, so there the extension keeps a tab on your claude.ai usage page, reads the usage percentages shown on it, and sends them to the desktop app over ws://localhost:27843 — a server on your own computer, not the internet. The token and cost figures still come from your local transcripts, exactly as on macOS.

The extension reads no other page and none of your conversations. Its cache lives in chrome.storage.local and never leaves your browser profile.

What is never read

  • Your conversations or prompts, in the browser or on disk.
  • Your payment method, card, invoices, or billing address.
  • Any website other than claude.ai's usage page (extension only, when in use).

Children

HUD for Claude is not directed at children under 13 and does not knowingly collect any data from them.

Changes to this policy

If the product ever starts reading different data, this policy will be updated and the "Last updated" date at the top of this page will change.
